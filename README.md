# Address Book in C

## Description
A console-based application developed in C to manage contacts, including names, phone numbers, and email addresses.

## Features
- Add, search, edit, and delete contacts
- List all contacts
- Save and retrieve contact details using file handling

## Technologies Used
- C Programming
- Structures and Functions
- File Handling

## Compilation and Execution
gcc *.c -o addressbook
./addressbook
